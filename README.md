# 하루매듭

초기 치매 환자의 일상 기록과 기억 회상을 돕고, 보호자가 통화·문자 위험 신호를 살펴볼 수 있도록 만든 AI 케어 플랫폼입니다. 비트교육 고급과정 42기 3조에서 진행한 팀 프로젝트의 공개용 소스입니다.

[포트폴리오 상세 페이지](https://choisung-ho.github.io/projects/harumaedeup/)

## 주요 기능

- **기억 회상** · 개인의 일상 기록을 검색해 답변에 활용합니다. 관련 근거가 부족하면 안전 응답으로 전환합니다.
- **일상 기록** · 사진과 영상, 위치 이력의 분석 결과를 일기와 이야기로 구성합니다.
- **통화·문자 분석** · 통화 음성을 텍스트로 변환하고, 규칙과 AI 문맥 분석을 이용해 위험 신호를 분류합니다.
- **보호자 앱** · Flutter에서 보호 대상 연결, 기록 확인, 복약·안전 구역 관리 화면을 제공합니다.

## 구조와 역할

앱의 상태 동기화와 AI 처리를 분리했습니다. 프로젝트에서 설계한 서버리스 구조는 Firestore와 Cloud Storage에 기록을 저장하고, Eventarc 이벤트를 받은 Cloud Run 또는 Firebase Functions의 처리 코드에서 분석을 수행하는 방식입니다.

최성호는 **PM · AI System / Backend Lead**를 맡아 요구사항과 개발 일정을 관리하고 AI 처리·백엔드 구조를 설계 및 구현했습니다. 배포 과정에서 팀원별 업무에 필요한 GCP 서비스 계정과 IAM 권한을 정리했습니다. 앱 화면과 서버에는 3조 팀원의 공동 작업이 포함되어 있습니다.

## 공개본과 확인 범위

팀 최종 소스의 주요 코드로 새 저장소를 구성했습니다. 독립 RAG 예제와 영상 서버 의존성 목록은 별도 AI 개발 자료에서 가져왔습니다. 원본 팀 저장소의 커밋, 계정 키, 앱 서명 파일, 실제 배포 주소, 사진·음성·분석 데이터는 포함하지 않았습니다.

서버 설정 항목은 [환경변수 예시](.env.example)에 정리했습니다. Flutter 폴더는 코드 열람용입니다. 실행하려면 별도의 Firebase 설정, 플랫폼 프로젝트, 로컬 패키지와 앱 자산이 필요합니다. 서비스 계정 키를 앱에 넣는 기존 알림 파일은 제외했습니다. 소스의 예시 주소는 실제 서비스로 연결되지 않습니다.

공개 전 Python 문법과 자격 증명 패턴을 검사했습니다. Flutter 빌드, 클라우드 배포, 지연 시간 및 위험 탐지 정확도는 이 공개본에서 검증하지 않았습니다.
